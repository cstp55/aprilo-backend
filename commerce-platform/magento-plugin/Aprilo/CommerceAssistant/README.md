# Aprilo Commerce Magento Module

This Magento 2 extension connects your e-commerce store with the Aprilo Commerce Assistant. It provides secure backend configuration, API integration, and custom frontend components.

## Features
- Secure Magento admin panel integration.
- API connectivity to Aprilo services.
- Custom Blocks and UI components.

## Requirements
- PHP 8.1 / 8.2 / 8.3
- Magento 2.4.x
