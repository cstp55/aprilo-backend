# Chapter 7 - Value Unit Framework

## Executive Summary

The company needs a value framework that makes AI measurable in business terms. Traditional AI metrics such as prompts, tokens, embeddings, model calls, and chat sessions are not enough for buyers or investors. The company should define its core value unit as the Operational Value Unit (OVU): a completed or meaningfully assisted business action that saves time, reduces cost, improves response quality, or accelerates a workflow.

An OVU is not simply an AI message. It is a measurable business event. Examples include an HR question resolved with source citation, an onboarding request completed, a policy answer delivered with permission control, an order status request deflected, a product record enriched, a purchase approval routed, or a report generated from operational systems.

This framework helps pricing, product design, financial modeling, investor storytelling, and customer ROI measurement align around the same unit of value.

## Research Findings

### 1. AI value realization remains a market challenge.

McKinsey and Deloitte research shows that AI usage is widespread but enterprise-level value realization is uneven. This supports the need for a metric that ties AI to business outcomes.

### 2. Customers buy outcomes, not AI components.

The Market Gap Discovery document established that businesses do not buy prompts, agents, vector databases, or embeddings. They buy cost reduction, time savings, better customer experience, faster decisions, and reduced manual work.

### 3. Workflow execution is more valuable than conversation.

Chapter 1 already defines the company's product philosophy: the company is not building another chatbot or agent builder; it is building reusable business capabilities powered by AI. The Value Unit Framework should make that measurable.

## Definition: Operational Value Unit

An Operational Value Unit is a measurable AI-assisted business outcome produced inside or around an operational workflow.

An OVU should meet at least one of the following criteria:

- Saves employee time.
- Reduces support or internal ticket volume.
- Completes a workflow step.
- Improves answer accuracy or search success.
- Deflects a repetitive request.
- Generates a business artifact.
- Routes an approval or exception.
- Updates or retrieves data from a business system.
- Improves compliance through auditability, permissioning, or source attribution.

## Value Unit Examples

| Domain | OVU Example | Measurable Output | Potential ROI Metric |
|---|---|---|---|
| HRMS | Employee policy question answered with citation | Resolved employee query | HR time saved, reduced repeat questions |
| HRMS | Onboarding checklist generated | Completed onboarding step | Faster onboarding, fewer manual HR touches |
| HRMS | Leave policy clarification routed | Correct policy response | Reduced HR ticket volume |
| Ecommerce | Order status request resolved | Support interaction deflected | Tickets reduced, CS time saved |
| Ecommerce | Product description enriched | Updated product content | Catalog quality, conversion influence |
| Ecommerce | Return request triaged | Workflow routed | Faster return cycle time |
| ERP | Purchase request drafted | Procurement workflow step | Time saved, fewer manual errors |
| ERP | Inventory exception summarized | Operational alert | Faster decision-making |
| CRM | Account summary generated | Sales prep artifact | Sales time saved |
| Support | Ticket reply drafted from knowledge base | Faster response | First-response-time reduction |

## OVU Measurement Model

| Measurement Layer | Metric | Purpose |
|---|---|---|
| Activity | Number of OVUs created | Shows usage volume |
| Quality | Accuracy, source attribution, user rating | Shows trust and usefulness |
| Completion | Workflow success rate | Shows execution reliability |
| Efficiency | Minutes saved per OVU | Converts usage to business value |
| Financial | Cost saved or revenue influenced | Converts operations into ROI |
| Risk | Escalation rate, approval rate, error rate | Shows governance quality |

## ROI Formulas

### Time Savings

Monthly time saved = number of resolved requests x average minutes saved per request.

Monthly labor value = monthly time saved / 60 x fully loaded hourly cost.

### Ticket Deflection

Ticket value = deflected tickets x average handling cost per ticket.

### Workflow Acceleration

Cycle-time improvement = old average completion time - new average completion time.

Monthly value = cycle-time improvement x number of workflows x cost or revenue impact per workflow.

### Accuracy and Risk

Risk reduction value is harder to quantify early. It should be measured through reduced error rate, fewer escalations, better audit trails, and fewer policy exceptions.

## Strategic Analysis

The Value Unit Framework gives the company a way to avoid weak AI metrics. A high number of chats is not proof of value. A high number of completed, verified, permission-aware operational outcomes is much stronger.

This framework also supports pricing. Instead of charging for raw model usage, the company can package plans by:

- Number of enabled capability packs.
- Number of monthly OVUs.
- Number of connected systems.
- Number of employees served.
- Advanced governance and analytics.

The framework also supports investor communication because it creates a bridge between product usage and revenue. If the company can show that each customer generates more OVUs over time, and that OVUs correlate with expansion revenue, it has a strong platform usage metric.

## Founder Decisions

1. Adopt Operational Value Unit as the internal value metric.

2. Instrument the product to track OVUs from the first MVP.

3. Avoid using chat count as the primary success metric.

4. Require each capability pack to define its OVU before development starts.

5. Use OVU data in customer ROI reports, pricing design, and investor updates.

6. Build dashboards that show time saved, workflows completed, tickets reduced, and user trust signals.
