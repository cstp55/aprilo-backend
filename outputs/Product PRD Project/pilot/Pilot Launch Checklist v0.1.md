# Pilot Launch Checklist v0.1

## Product

AI HR Knowledge & Workflow Assistant

## Pilot Workflow

Employee HR Policy Q&A with source citations, safe escalation, and ROI measurement.

## Pilot Goal

Prove within 30 days that the assistant can reduce repetitive HR work while maintaining trust, safety, and source-grounded answers.

## Pre-Pilot Qualification

The customer is qualified if:

- Company has 50-1,000 employees.
- HR team receives repeated employee questions.
- HR documents are available.
- HR owner can review escalations.
- Customer accepts document-first MVP.
- Customer agrees to measure success.
- Customer does not require payroll or HRMS write actions in first pilot.

## Required Customer Inputs

### Documents

Minimum:

- Employee handbook.
- Leave policy.
- Remote/hybrid work policy.
- Onboarding guide or checklist.
- Expense/reimbursement policy, if available.
- HR contact/escalation information.

Optional:

- Benefits overview.
- Top 20 repeated HR questions.
- Anonymized sample HR tickets.
- Existing FAQ.

### People

Required:

- HR pilot owner.
- HR admin reviewer.
- 20-100 pilot employees.
- IT/security contact, if needed.

### Baseline Metrics

Collect before launch:

- Estimated weekly HR questions.
- Current HR response time.
- Current support channel: Slack, Teams, email, helpdesk, portal.
- Estimated time spent answering repeated questions.
- Top repeated topics.

## Setup Checklist

### Workspace

- Create organization workspace.
- Add HR admin.
- Add owner/founder contact.
- Add pilot employee users.
- Confirm role assignment.

### Knowledge

- Upload approved HR documents.
- Add source titles and owners.
- Set source access scope.
- Confirm indexing completed.
- Test top 10 pilot questions.

### Safety

- Configure sensitive-topic categories.
- Confirm escalation owner.
- Test unsupported-answer fallback.
- Test sensitive-topic escalation.
- Confirm no payroll/medical/performance data uploaded.

### Metrics

- Configure time-saved assumption.
- Confirm dashboard date range.
- Confirm resolved/escalated definitions.
- Record baseline metrics.

## Launch Checklist

Before inviting employees:

- HR admin approves test answers.
- Escalation flow works.
- Audit log records questions.
- Feedback buttons work.
- Dashboard shows test activity.
- HR owner understands pilot scope.
- Employees receive simple launch instructions.

## Weekly Pilot Rhythm

### Week 1: Controlled Launch

Review:

- First employee questions.
- Incorrect or low-confidence answers.
- Escalations.
- Knowledge gaps.

Decision:

- Continue, adjust sources, or narrow scope.

### Week 2: Usage Expansion

Review:

- Question volume.
- Resolution rate.
- Helpful rate.
- Top topics.

Decision:

- Add more pilot employees if trust is good.

### Week 3: Optimization

Review:

- Missing sources.
- Repeated unsupported questions.
- Admin workload.
- Employee feedback.

Decision:

- Add FAQ entries or source updates.

### Week 4: ROI Review

Review:

- Total questions.
- Resolved questions.
- Escalated questions.
- Estimated time saved.
- Top knowledge gaps.
- Trust incidents.
- HR admin feedback.

Decision:

- Convert to paid subscription, extend pilot, or stop.

## Pilot Success Criteria

| Area | Success Target |
|---|---:|
| Usage | 50+ employee questions in 30 days |
| Resolution | 50%+ resolved without HR escalation |
| Helpfulness | 70%+ helpful rating where rated |
| Trust | 0 high-severity privacy/access incidents |
| Admin value | HR identifies useful knowledge gaps |
| ROI | HR confirms time saved or support reduction |
| Commercial | Customer agrees to continue, expand, or discuss paid plan |

## Pilot Failure Signals

Investigate if:

- Employees do not use the assistant.
- HR documents are too poor to answer basic questions.
- Helpful rate is below 50%.
- Sensitive questions receive unsafe answers.
- Admin must manually fix most answers.
- Customer refuses to define success metrics.

## Pilot Closeout Deliverables

At the end of the pilot, produce:

1. Pilot summary.
2. Usage metrics.
3. Resolution and escalation metrics.
4. Time-saved estimate.
5. Top employee topics.
6. Top knowledge gaps.
7. Customer quote or testimonial, if positive.
8. Conversion recommendation.
9. PRD v0.2 update notes.

## Founder Decision

The first pilot should be document-first. HRMS integration is not required to prove the core workflow.
